# visual-programming-labs-kotok

Лабораторные работы по дисциплине «Технологии визуального программирования».

## **Структура**
- `lab1/` — Лабораторная работа №1. Моделирование процессов с использованием Git и визуальных нотаций
    - `docs/` — текстовые описания и Mermaid-файлы
        - `process_description.md` — описание бизнес-процесса
        - `sequence.md` — Sequence Diagram
        - `flowchart.md` — Flowchart
    - `diagrams/` — графические диаграммы
        - `process.bpmn` + `process-bpmn.png` — BPMN
        - `activity.drawio` + `activity-uml.png` — UML Activity
    - `report.md` — отчёт по лабораторной работе
