# Sequence Diagram — сценарий «Бронирование номера с успешной и неуспешной оплатой»

Диаграмма показывает обмен сообщениями между клиентом, менеджером по бронированию,
системой управления отелем (PMS) и бухгалтерией на этапе оформления и оплаты брони.

```mermaid
sequenceDiagram
    participant Клиент
    participant Менеджер as Менеджер по бронированию
    participant PMS as Система PMS
    participant Бухгалтерия

    Клиент->>Менеджер: Запрос на бронирование номера (даты, категория)
    Менеджер->>PMS: Проверить наличие свободных номеров
    PMS-->>Менеджер: Результат проверки (номер найден)
    Менеджер->>Клиент: Предложение номера и расчёт стоимости
    Менеджер->>Клиент: Напоминание: оплата в течение 15 минут

    par Параллельная обработка после согласия клиента
        Менеджер->>PMS: Зарезервировать номер (заблокировать)
    and
        Менеджер->>Бухгалтерия: Сформировать счёт на оплату
    end

    Бухгалтерия->>Клиент: Направить счёт на оплату

    alt Оплата поступила вовремя
        Клиент->>Бухгалтерия: Оплатить счёт
        Бухгалтерия->>PMS: Подтвердить оплату
        PMS-->>Менеджер: Статус брони: подтверждена
        Менеджер->>Клиент: Подтверждение бронирования и инструкции по заезду
    else Оплата не поступила в срок
        PMS-->>Менеджер: Истёк срок ожидания оплаты
        Менеджер->>PMS: Отменить бронирование, освободить номер
        Менеджер->>Клиент: Уведомление об аннулировании брони
    end
```
