# Flowchart — алгоритм «Проверка наличия номеров и расчёт стоимости бронирования»

Блок-схема детализирует шаги 3–5 бизнес-процесса: проверку свободных номеров,
подбор альтернативы при их отсутствии и расчёт итоговой стоимости проживания.

```mermaid
flowchart TD
    A([Начало]) --> B[Получить параметры заявки:
даты, категория, число гостей]
    B --> C[Проверить наличие свободных
номеров в PMS на заданные даты]
    C --> D{Номер нужной
категории свободен?}
    D -- Нет --> E[Подобрать ближайшую
альтернативу: другая категория
или другие даты]
    E --> F{Клиент согласен
на альтернативу?}
    F -- Нет --> G([Конец: заявка отклонена])
    F -- Да --> H[Зафиксировать
выбранный вариант]
    D -- Да --> H
    H --> I[Рассчитать базовую стоимость
за количество ночей]
    I --> J{Есть скидка
или промокод?}
    J -- Да --> K[Применить скидку
к итоговой сумме]
    J -- Нет --> L[Оставить базовую сумму
без изменений]
    K --> K2[Проверить максимальный размер скидки]
    K2 --> M[Добавить стоимость
дополнительных услуг]
    L --> M
    M --> N[Сформировать итоговый счёт]
    N --> O([Конец: счёт готов
к отправке клиенту])
```
