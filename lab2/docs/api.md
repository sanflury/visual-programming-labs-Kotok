## Обзор

Три GET-эндпоинта реализованы в Node-RED в потоке `08-endpoints`.  
Документация с UI доступна по адресу: `http://localhost:1880/docs`

## GET /api/text

Возвращает простой текстовый ответ.

**Ответ 200:**
```
Привет от Коток! Это текстовый ответ.
```

## GET /api/info

Возвращает JSON с информацией о студенте.

**Ответ 200:**
```json
{
  "student": "Коток",
  "group": "УИР-241",
  "lab": 2,
  "timestamp": 1791309500000
}
```

## GET /api/items

Возвращает элемент по query-параметру `id`.

**Параметры:**
| Имя | Тип | Обязательный | Описание |
|---|---|---|---|
| `id` | string | да | идентификатор элемента |

**Ответ 200:**
```json
{"id": "1", "name": "Номер 1", "price": 5000, "currency": "BYN"}
```

**Ответ 400 — параметр не передан:**
```json
{"error": "Bad Request", "message": "Параметр id обязателен"}
```

**Ответ 404 — элемент не найден:**
```json
{"error": "Not Found", "message": "Элемент с id=99 не найден"}
```

**Примеры запросов:**

- `http://localhost:1880/api/items?id=1` — успех
- `http://localhost:1880/api/items?id=99` — 404
- `http://localhost:1880/api/items` — 400

## Swagger / OpenAPI документация (Ачивка 4)

Документация реализована **вручную** — HTML-страница со списком эндпоинтов и кликабельными ссылками для тестирования.

**Доступ:** `http://localhost:1880/docs`

Автоматический генератор `node-red-contrib-scalar-docs` не установился в Docker-образе Node-RED из-за несовместимости зависимостей, поэтому была создана статическая HTML-документация с UI.
